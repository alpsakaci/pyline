# PyLine Core

A lightweight Python framework for implementing the CQRS pattern with pipeline orchestration.

## Key Features
- **Separation of Concerns**: Decouple logic into Commands and Queries.
- **Mediator Pattern**: Centralized dispatching for handlers.
- **Pipeline Orchestration**: Seamlessly chain steps with shared context.
- **Type Safe**: First-class support for Python type hints and overloads.
